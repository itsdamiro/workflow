# Closing a slice

The checklist lives in the project, not here: read `docs/CLOSING_A_SLICE.md` and follow it step by step. Copy its checklist into your working notes and tick it as you go, including its "return to" lines.

If the file is missing, the project has not adopted the template: say so and offer to run the template's `adopt.sh <project>` (the `template/` folder of the workflow repository). Do not improvise a different checklist.

Run commands the project already has (`scripts/gates`, `scripts/mutate.py`) instead of retyping them. Commit and push only when the owner says so.
